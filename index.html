How flagging works

Only the issue's title, summary, reference and “Watch for” note are checked. Each pattern is case-insensitive and must begin at a word boundary; it may continue into a longer word (for example, “abatement” matches “abatements”). The first qualifying match of each watchlist term counts once.

If any Core construction term matches, the issue is flagged Construction. Otherwise, if a Business-wide term matches, the flag is Business-wide. Otherwise it is Not flagged. “New” means the item's date_added is the latest date_added across all tracked items. Flag counts represent issues, not the total number of matching terms.
